# 万格画布

Next.js App Router + React + TypeScript + 98.css 的可交互原型。参考 ayoo 的目录分层，独立项目，不依赖或修改 ayoo。

## 启动

```bash
pnpm install
pnpm dev
```

默认访问 http://localhost:3000 。`pnpm build` 构建生产版本，`pnpm start` 启动。

## 架构

- `app/`：Server Component 路由、根布局、全局样式。
- `components/canvas/`：页面组件、Canvas 画布、小地图、原生 dialog、局部状态和 CSS Module。
- `lib/grid.ts`：100 × 100 坐标、价格、确定性演示数据、持久化数据校验。
- `public/art/`：本地 SVG 示例作品；`scripts/generate-art.mjs` 可重新生成。

## 已实现

一万个格子，直接在画布上逐格多选，支持不连续位置；再次点击取消，可一键清空。已占用格子自动跳过，拖拽只移动画布不添加格子。「查看作品」模式用于浏览既有作品。总价为实际选中格数 × 2 USDG。先购买并保存精确格子列表，无需上传图片；购买后在「我的格子」点击区域，上传一张图片并保存作品，按选区包围矩形铺图、裁切到所选格子，未选择的位置不收费、不占用、不覆盖。购买前重新验证占用冲突。

上传 JPG/PNG/WebP/GIF（最大 5 MB），保留图片比例、最长边压缩到 1024 像素，GIF 使用静态帧。「我的格子」高亮所有已购买格子（含待上传区域），「我的作品」仅列出已保存图片的作品。「只看空位」用淡绿色标记可购买格子、淡红色标记已出售格子。支持区域预览、演示购买、刷新恢复及从区域内任意格查看完整作品。旧单格和旧矩形记录继续兼容读取。

支持三级缩放、拖拽平移、单击原地选区、键盘移动、坐标定位、小地图跳转、空位筛选，以及标题栏整窗拖动、最小化/最大化。桌面背景固定，移动端内容在窗口内滚动。

## 演示边界

未接入钱包、智能合约、USDG 支付、图片存储服务或后端。购买不签名、不扣款，记录只保存到当前浏览器 localStorage。社区占用格子是确定性示例。生产接入时需配置目标链与 USDG 地址、合约购买和占用校验、交易确认、服务端图片验证与存储；不能把本地状态当作链上所有权。

## 示例画布素材

`public/art/generated/` 保存 10 张通过内置 imagegen 生成的像素插画，提示词见同目录 `prompts.json`。示例画布采用固定种子的随机布局，76 块作品区域、尺寸 4×4 到 9×8 格；图片整张跨格显示。刷新不重新洗牌，旧购买记录优先保留，示例作品遇到已有购买格子会避让，计数不重复。

「我的格子」显示已发布图片与未上传的蓝色格子。逐格多选未上传格子（可跨购买批次、不连续），上传并确认后创建一份锁定作品；未选中的已购格子继续保留。发布时重新校验所有权及未上传状态，已发布格子不可再次上传或修改。此限制目前由本地演示逻辑执行。

## 桌面工具

「交易」展示 USDG / WANGE 的 Swap 界面，WANGE 为占位币种，无实时报价或交易功能。「设置」支持中英文界面切换（保存至当前浏览器）和演示钱包连接 / 断开；不调用真实钱包。
